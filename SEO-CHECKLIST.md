## 📋 Checklist tiếp theo

### Sau khi deploy:

1. **Google Search Console**

   ```
   - Xác minh domain muahackvip.com
   - Submit sitemap: https://muahackvip.com/sitemap.xml
   - Request indexing cho homepage
   - Theo dõi Core Web Vitals
   ```

2. **Google Analytics 4**

   ```
   - Tạo property mới
   - Cập nhật VITE_GA_MEASUREMENT_ID trong .env
   - Test tracking events
   ```

3. **Bing Webmaster Tools**

   ```
   - Đăng ký và xác minh domain
   - Submit sitemap
   ```

4. **Facebook Domain Verification**

   ```
   - Xác minh domain trong Business Manager
   - Test Open Graph tags với Facebook Debugger
   ```

5. **Performance Testing**
   ```
   - PageSpeed Insights: https://pagespeed.web.dev
   - GTmetrix: https://gtmetrix.com
   - Mobile-Friendly Test: https://search.google.com/test/mobile-friendly
   ```
