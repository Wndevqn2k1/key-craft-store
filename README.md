# Key Craft Store

A modern e-commerce platform for mechanical keyboards and accessories.

## Getting Started

### Prerequisites

- Node.js & npm - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd key-craft-store

# Install dependencies
npm i

# Start the development server
npm run dev
```

## Tech Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Development

The development server runs with auto-reloading and instant preview. Make your changes and they will be reflected immediately in your browser.
